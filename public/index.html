MCP servers give Claude Code extra tools. User servers load in every project and live in ~/.claude.json. Project servers live in the repo's .mcp.json, so they are shared with anyone who clones it - and Claude Code will not start one until it has been approved for that project, which is the state shown on each row. Local servers are yours alone on this machine. Choose a project above to see the last two. Adding a server arranges for a command to run the next time Claude Code starts, so treat it with the same care as a hook.

Add or replace a server

An existing server of the same name in the same scope is replaced. A copy of the file is kept alongside it before anything is written.
